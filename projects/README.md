# Projects

Choose one of the following projects. Each project contains a Jupyter notebook, datasets, and supporting material.

## 1. Lysozyme thermal stability

Study the heat denaturation of lysozyme using circular dichroism (CD) spectroscopy. The project includes CD spectra, secondary-structure analysis, two-state modelling, data fitting, and molecular-structure visualisation. Start with [notebook1.ipynb](notebook1/notebook1.ipynb).

## 2. Kinetics and thermodynamics using NMR

Investigate molecular structure, reaction kinetics, and thermodynamics with NMR data. The project covers the synthesis of paracetamol and agostic/non-agostic interactions in an iridium pincer complex, including spectral analysis, rate fitting, and structure visualisation. An additional notebook demonstrates interactive, time-resolved NMR visualisations. Start with [notebook2.ipynb](notebook2/notebook2.ipynb).

## 3. *E. coli* growth data

Process and analyse microplate growth data from *Escherichia coli*. The project covers plotting growth curves, automating the processing of replicated datasets, calculating averages and variation, and estimating microbial growth rates. Start with [notebook3.ipynb](notebook3/notebook3.ipynb).
